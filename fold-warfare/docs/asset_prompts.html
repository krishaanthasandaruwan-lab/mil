How to use (open me first)## How to make the images (read once) 1. Open **Gemini → Nano Banana** (image generation). 2. **Attach your concept picture** (the ENEMY SECTOR / ALLY SECTOR image) to every *text* prompt. It's the style reference that keeps every asset looking like one game. 3. Prompts marked **EDIT** are not made from text. Upload the image named in "Edit of", then paste the prompt. This keeps the same unit identical across states and teams (blue → red, idle → firing → wreck). 4. Save each result as **PNG** with the **exact file name** shown (e.g. `tank_blue_idle.png`) into: `fold-warfare/art_raw/` 5. Run `npm run assets` (or ask me). The script removes the green background, trims, resizes and the game picks the image up automatically. Missing images keep using the built-in drawings, so you can add them one by one. **Tips** - If you see a shadow, floor or gradient behind the object, regenerate. The background must be flat green. - Keep green out of the units. Team colors are blue and red only. - After the first good unit (`tank_blue_idle`), attach it **as a second reference** for the other units so all units share the same detail level. - Make things in this order: Tier 1 → Tier 2 → Tier 3. Tier 1 alone already makes battles look like the concept. ## Animations - what you need to make Very little. The game animates the images in code: | Animation | Done by | |---|---| | Units dropping in, idle bob, hover (mine drone), recoil when firing | Code | | Firing | Code swaps to the `_fire` image for a moment + muzzle flash + projectile | | Mortar shell arc, missile flight with smoke trail, tracer bolts | Code (uses `fx_shell`, `fx_missile`, `fx_laser_bolt`) | | Explosions, sparks, smoke, debris, screen shake | Code particles + optional `fx_explosion_sheet` | | Hide skill (shimmer/cloak), shield dome pulse, hologram range circles | Code | | Unit death | Code swaps to `_wreck` (tank) or fades out; bunker goes intact → damaged → destroyed | | Fold of the phone, banners, stars, coin counters | Code | The only frame-by-frame animation is `fx_explosion_sheet` (16 frames in one image). It's optional.
